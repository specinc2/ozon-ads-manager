Прокси для анализатора цен

Прокси используется для парсинга цен на Ozon/AliExpress (обход антибота). Укажите срок действия, чтобы видеть, сколько дней осталось.

Как получить куки из Network (1 минута, правильный способ):
1. Отключите VPN и откройте https://www.ozon.ru в браузере — дождитесь полной загрузки.
2. Нажмите F12 → вкладка «Сеть/Network» → обновите страницу (F5) → кликните первый запрос → вкладка «Заголовки/Headers» → раздел «Request Headers» → найдите строку «Cookie:» → выделите и скопируйте всё значение после «Cookie:» (длинная строка вида abt_data=7.xxx; __Secure-access-token=xxx; xcid=xxx; rfuid=xxx; _ozon_session=xxx).
3. Вставьте эту строку целиком в поле выше и нажмите «Сохранить прокси».
Важно: копируйте из Network, а не из Application. Куки из Application по одной часто не работают — нужны все сразу как единый Cookie-заголовок.

Bright Data — цены Ozon (официальный API)

Bright Data — официальный сервис сбора данных: отдаёт цены товаров Ozon напрямую (без обхода антибота). У каждого аккаунта — своё подключение.

Найти: brightdata.com → панель → ваш API-ключ.
Найти: brightdata.com → Datasets → Ozon → ID набора данных.
Не забудьте пополнить счёт Bright Data! Без активного баланса запросы не выполняются (ошибка «Customer is not active»). Пополнение: brightdata.com → Billing.

Плагин браузера (цены Ozon)

Плагин читает карточку Ozon прямо в вашем браузере и автоматически отправляет цену и страну поставки (РФ/Китай). Антибот не нужен.

  1. Токен: {{ proxy_setting.plugin_token if proxy_setting and proxy_setting.plugin_token else 'не создан' }} {% if not (proxy_setting and proxy_setting.plugin_token) %} — создать на странице «Цены плагина» {% endif %}
  2. Скачайте расширение: папка extension из проекта.
  3. Chrome → chrome://extensions → «Режим разработчика» → «Загрузить распакованное» → выберите папку extension.
  4. Откройте иконку плагина → вставьте токен → Сохранить.
  5. Открывайте карточки Ozon — цены собираются автоматически (см. список).
