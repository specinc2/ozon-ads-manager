Как пользоваться приложением

Ozon Ads Manager — инструмент для управления рекламой Ozon (Performance API) и контроля экономики товаров. Ниже — пошаговые инструкции по всем разделам.

{% if not user %}
Сейчас вы смотрите страницу как гость. Чтобы начать работу, пройдите регистрацию — это займёт минуту.
{% endif %}

  1. Зарегистрируйтесь — нажмите «Зарегистрироваться» и создайте логин, email и пароль.
  2. Добавьте ключи Performance API (раздел «Настройки»):
    • Client-Id и Client-Secret берутся из ЛК Ozon → Настройки → API-ключи (вкладка «Performance API»).
    • Ключи проверяются автоматически при добавлении — если всё верно, появится «добавлены и проверены».
  3. Подключите Seller API (тот же раздел «Настройки») — Client-Id и Api-Key из той же страницы ЛК, вкладка «Seller API». Это нужно, чтобы автоматически подтягивать остатки, цены, комиссии и оборот товаров.
  4. Готово! Переходите к «Кампаниям».
Все ключи хранятся в зашифрованном виде в базе данных и не выводятся в интерфейсе.

Первая загрузка

Нажмите кнопку «Синхронизировать» — список ваших рекламных кампаний Ozon загрузится в таблицу. Статусы и типы обновляются автоматически каждые 5 минут.

Что видно в списке
  • Бюджет — дневной (₽/день) или недельный (₽/нед), в зависимости от настройки кампании.
  • Расход — суммарный расход за период.
  • ДРР — доля рекламных расходов от оборота: зелёный < 5%, жёлтый 5–10%, красный > 10%.
  • Корзина — сколько раз товары добавили в корзину.
  • Прогресс — сколько % бюджета израсходовано (полоса краснеет при > 80%).
  • Товары — сколько товаров загружено; «не загружены» — нажмите кнопку «Загрузить товары всех кампаний».
Управление
  • Кнопки ▶/⏸ запускают и останавливают кампанию.
  • В карточке кампании (клик по названию) — изменение дневного/недельного бюджета, ставки товаров (по одному и массово), график динамики.
Кнопка «Загрузить товары всех кампаний» проходит по всем кампаниям с прогресс-баром — при первом входе запускается автоматически.

Раздел «Товары» — сводная экономика по каждому артикулу из ваших рекламных кампаний.

Что подтягивается из ЛК автоматически (Seller API)
  • Цена продажи, комиссия маркетплейса %, логистика ₽/шт, эквайринг %.
  • Остатки на складах, участие в акции (со скидкой).
  • Заказы и выручка за месяц — весь оборот артикула.
Что нужно заполнить вручную
  • Себестоимость — единственное поле, которого нет в API Ozon. Введите её в столбце «Себестоимость» и нажмите галочку ✓ для сохранения.
  • % выкупа — метрика выкупов сейчас недоступна в Seller API (помечена устаревшей), поэтому вводится вручную в модальном окне «⚙» при необходимости.
Рассчитывается автоматически
  • Маржа/шт — цена минус себестоимость, комиссия, логистика, эквайринг.
  • Маржа с выкупом — с учётом % выкупа (возвраты съедают прибыль).
  • Лимит рекламы/шт — сколько ₽ рекламы допустимо на 1 продажу, чтобы сохранить минимальную маржу.
  • ДРР от оборота — рекламный расход / (рекламная выручка + органический оборот).
  • «Мало показов» — товары с посещаемостью менее 100 показов и 5 заказов подсвечиваются жёлтым.
Чтобы ДРР от оборота и лимит рекламы считались корректно, у товара должны быть заполнены цена и месячная выручка (автоматически из ЛК).

Раздел «Бидер» — правила, которые сами меняют рекламные ставки товаров. Правила выполняются каждые 5 минут; каждое изменение фиксируется в журнале с причиной.

Стратегия «Целевая ДРР от оборота»

Задаёте целевую ДРР (например 10%). Если реклама тратит больше 10% от всего оборота артикула — ставка снижается; если расход меньше половины цели и маржа позволяет — ставка повышается. Требование: у товара заполнена месячная выручка (из ЛК).

Стратегия «Поддержание позиции»

Через API конкурентных ставок Ozon узнаём, сколько ставят конкуренты, и держим свою ставку чуть выше порога целевой позиции (топ-3, топ-10, топ-20) с множителем 1.05 (+5%). Работает для кампаний «Оплата за клик».

Стратегия «ИИ-подбор»

Имитирует ручной подбор: начинаем с нижней ставки, шагами повышаем, анализируем CTR и ДРР за период теста, останавливаемся при достижении цели или падении CTR ниже минимума. Полезно для поиска ставки «вслепую».

Рекомендации по использованию
  • Сначала укажите себестоимость и проверьте маржу в «Товарах» — бидер работает поверх экономики.
  • Ставьте ограничения min/max ставки, чтобы не уйти в крайности.
  • Запускайте правило на 1–2 товарах, смотрите журнал, потом расширяйте.

Дашборд (главная страница)
  • Расход, заказы, CPA и ROMI за неделю.
  • Статусы кампаний (сколько активных, остановленных и т.д.).
  • Показатели за месяц и непрочитанные уведомления.
  • Кнопка «Обновить статистику» — принудительный сбор данных из Ozon.
Статистика
  • Выберите кампанию (или «Все кампании») и период: 7 / 14 / 30 / 90 дней.
  • Сводные карточки: расход, показы, клики, заказы, выручка, ДРР.
  • График динамики по дням + детальная таблица.
  • Кнопка «Экспорт CSV» — выгрузка таблицы в Excel/Google Таблицы.
При выборе «Все кампании» динамика суммируется по датам — удобно смотреть общую картину.

Авто-правила (раздел «Авто-правила»)
  • Стоп по бюджету — кампания останавливается при 100% расхода дневного/недельного бюджета (предотвращает перерасход).
  • Уведомление по бюджету — оповещение при достижении порога (например 90%), без остановки.
  • Авто-ставки — если CTR ниже X% — снизить ставку на Y%, и т.п. (для отдельных товаров или всех).
Расписания (раздел «Расписания»)

Кампания автоматически запускается и останавливается в заданные дни недели и часы (с часовым поясом). Пример: активна только по будням с 10:00 до 23:00.

Автоматика выполняется каждые 5 минут — действие может произойти с задержкой до 5 минут.

Журнал
  • Действия — кто и когда запустил/остановил кампанию, какие авто-правила и бидер сработали, изменения ставок и бюджетов (с параметрами).
  • Запросы к Ozon API — отладочная информация: эндпоинт, метод, статус, ошибка. Секреты не логируются.
Уведомления

В интерфейсе (колокольчик на дашборде) — достижение бюджета, срабатывание правил, ошибки API. Отмечаются прочитанными автоматически.

Безопасность
  • Пароли хранятся в виде хеша (PBKDF2).
  • Ключи Ozon шифруются (Fernet) и не выводятся на экран.
  • Сессия — подписанная HttpOnly-cookie.

«Ключи не прошли проверку»
  • Проверьте, что Client-Id и Client-Secret скопированы целиком, без пробелов.
  • Убедитесь, что ключ относится к Performance API (не Seller API).
  • Ключи в ЛК Ozon могли быть перевыпущены — создайте новые.
Кампаний нет после синхронизации
  • Ключ может относиться к другому аккаунту/сервисному аккаунту.
  • Проверьте в ЛК Ozon, что рекламные кампании существуют.
«Товары не загружены»

Нажмите «Загрузить товары всех кампаний» или откройте карточку кампании — товары подтянутся. У некоторых типов кампаний (блогеры, ВК) товаров нет по своей природе — это нормально.

Не видно ДРР и корзины

Эти метрики приходят из сводного отчёта Ozon для кампаний «Оплата за клик». Нажмите «Обновить статистику» на дашборде.

Нужно больше кампаний (лимит)

По умолчанию синхронизируется до 100 кампаний — этого достаточно для большинства аккаунтов.
